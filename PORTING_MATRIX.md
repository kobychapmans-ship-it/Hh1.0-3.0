## Structured selectable units

32 new/ported units and characters are generated as selectable entries with points, stat lines, source text and the major listed options.

## Existing-entry patches

- Krios Irradiation Blaster option (+40) is attached to the Krios entry when found.
- Nullificator and Veteran disintegration weapon options are attached when the matching base entries are found.
- The five new Consul types are attached to Legion Centurion entries when found.

## Validation philosophy

The tool never guesses a missing base entry ID. It resolves entries/categories by normalized names at build time. If a base entry cannot be found, it records a warning in `generated/hh141-build-report.json` and still inserts the full rules card for that source section.
