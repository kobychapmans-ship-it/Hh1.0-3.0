THE ORDERS OF THE PROSCRIBED TECHNO ARCANA

Any Traitor aligned Magos Prime/Archmagos Prime can take one of the following Techno Arcana instead of the usual ones.
This does not mean they cannot take the usual ones. All of the same rules for using Techno Arcana still apply.
Cybertheurgic Weapons function in the same way as Cybertheurgy powers but are mainly shooting attacks on enemy
units. A model may still only use one Cybertheurgy power per turn.




MALEFIKITE ………………………………………………………………………+30 Points
A model with this Proscribed Techno-arcana gains all of the special rules listed here:

• Bonds of Corruption: Any unit with a Cybernetica Cortex that is in the same Detachment as a model with this
Proscribed Techno-arcana may have the Ruinous Cybernetica special rule.

 • Magister Malefica: A model with this Proscribed Techno-arcana gains the Machina Malefica Cybertheurgy powers, but
the controlling player may not select any other Cybertheurgy powers from those available for the model.

• Malignant Vector: During any Shooting phase, instead of making a Shooting Attack, the controlling player of a model
with this Proscribed Techno-arcana may select any friendly unit with the Cybernetica Cortex Special rule has at least one
model within 2" of model with this Proscribed Techno-arcana and roll a D6 for it on the following table:

D6 RESULT

1 The selected model suffers no further effect.

2-3 All models count as passing their Leadership test for their Ruinous Cybernetica Roll for the turn.

4+ All models count as passing their Leadership test for their Ruinous Cybernetica Roll for the rest of the game.



RUINOUS CYBERNETICA

At the start of the controlling player’s Shooting phase, that player can make a Leadership test for any units made up
entirely of models with this special rule. If that test is passed, until the end of the turn:

• All models in the unit are not subject to the Programmed Behaviour special rule.

• At the start of the Charge sub-phase, a Charge must be declared for this unit if there is an enemy unit within 12", and the
closest enemy unit must always be selected as the target of this Charge if possible (if multiple eligible units are equally
distant then the controlling player must select one of those eligible units to be the target of the Charge). This means that
in some cases they may charge a different target then they shot in the shooting phase.

If that test is failed, the unit suffers one Wound, allocated by the controlling player. No Saving Throws or Damage
Mitigation rolls of any kind may be made against this Wound.

CYBERTHEURGY POWERS: MACHINA MALEFICA

A Cybertheurgist with this Arcana gains all of the Rites, Weapons and other special rules listed here.



Indicium Malefica (Cybertheurgic Power)

A Cybertheurgist with this Cybertheurgic Rite may use it instead of making a Shooting Attack in the controlling player’s
Shooting phase. The model makes a Cybertheurgy test with no modifiers. If they fail, noting happens. If a double 6 is
rolled, the model takes a wound with no saves of any kind allowed. If Successful, the controlling player may select a
single enemy unit and roll a D6 for each model (excluding Vehicles) in that unit that is within 6" of the Cybertheurgist
model. For each result that equals or beats that model’s Save characteristic, that model’s unit suffers one Wound,
allocated by the Active player. Saving Throws and Damage Mitigation rolls can be taken against this Wound as normal. The
controlling player then rolls a D6 for each affected Vehicle. For each result of 6, one affected model with the Vehicle Unit
Type suffers a Crew Stunned result from the Vehicle Damage table and loses a hull point.

The Cybertheurgist may choose to add a -2 modifier to the Cybertheurgy test. If successful, every enemy model within 6"
of the Cybertheurgist model is affected instead.



Diabolis Quiritatus (Cybertheurgic Weapon)

Range    S         AP       TYPE

18’      6         3        Assault 3, Data-djinn, Rending, Cybertheurgic Focus

Data-Djinn: This attack only works on Vehicles and models with the Cybernetica Cortex Special rule.

Cybertheurgic Focus: Before making any To Hit rolls with this weapon, the Cybertheurgist must make a Cybertheurgy
test with no modifiers. If the Check is passed then the Cybertheurgist may attack as normal using the profile shown for
this weapon. If the Check is failed then the Cybertheurgist suffers Cybertheurgic Feedback, and nothing happens. On a
double 6, the model suffers a wound with no saves of any kind allowed and cannot use the weapon this turn.

CORRUPTED ENGINES SUPPLEMENTARY LIST



The following section presents rules for using a selection of Corrupted Engines in games of
Warhammer: The Horus Heresy – Age of Darkness 1.0. These rules are Expanded units for
the Mechanicum Army List and may be selected for a Detachment with the Mechanicum
Faction that has the Traitor allegiance, or included as part of an Allied Detachment of that
Faction. The following special rules apply to some or all of the units included in this section
– see the respective profiles for more details, In addition, ignore any Deep strike special
rules for Daemon engines.

Legion Praevian and Corrupted Engines

An army that includes a Legion Praevian may take a single unit of Corrupted Engines
instead of Castellax Battle-automata Maniple or a Vorax Battle-automata Maniple. If a
Corrupted Engine Unit type is chosen via this rule, it does not form part of the same Force
Organisation choice as the Legion Praevian with the Master of Cybernetica special rule and
must instead occupy its own appropriate Force Organisation choice*.

 An army can include a maximum of one unit of Corrupted Engines chosen in this manner,
regardless of the number of Legion Praevians within the army. Additional Legion Praevians
beyond the first may select a Castellax Battle-automata Maniple or a Vorax Battle-
automata Maniple via the Master of Cybernetica rule as normal.

*The chosen unit fills the available slot as if it was selected as a separate choice i.e., a
Decimator chosen via this rule would use a Elites slot when chosen. If none are available, it
cannot be chosen.

Animatus Malevolence (Cybertheurgic Rite)

Instead of making a Shooting Attack, a Cybertheurgist with this Cybertheurgic Rite may select a
single friendly unit within 12" that is entirely composed of models that are Corrupted Engines and
roll to activate a cyberthurgy power as normal with no modifiers If the test is successful then apply
one of the following effects:

      •   The chosen unit may immediately move a number of inches up to its unmodified Initiative
          Characteristic directly towards the nearest enemy unit. If the chosen unit has mixed
          Initiative Characteristics, use the highest unmodified Characteristic.
      •   All models in the chosen unit improve their Invulnerable Save by 1, to a maximum of 3+,
          until the beginning of the controlling player’s next turn, (e.g., a model with an Invulnerable
          Save of 5+ improves their save to 4+). •
      •   All models in the unit add 1 to their WS and I characteristics until the end of the subsequent
          Assault phase.

The Cybertheurgist’s controlling player may attempt to select two effects instead. If the player
wishes they must roll for the Cybertheurgy power as normal. If the Check is successful then two
different options chosen from the above list may be applied to the target unit instead of one. If the
Check is failed then no options may be chosen – the Corrupted unit then rolls on the Cyberthurgic
Mishap table and apply the effects to all models in the unit

QUESTORIS HOUSEHOLD DARK BLESSINGS



The following section presents expanded options for Questoris Household list.

Any Lords of War choice selected as part of a Questoris Household Detachment may
select one upgrade from those included in these rules, but note that some upgrades are
limited to certain units or may only be selected a limited number of times as noted in their
description.

A Lords of War choice selected from the Divisio Tactica: Questoris Household army list to
fill a Lords of War Detachment slot selected for an army whose Primary Detachment is not
a Questoris Knight Household Detachment may select a single option from those included
here.

A model with the Loyalist special rule cannot have any of the upgrades included within the
following section.

Any model that has one or more upgrades from the following section gains the Traitor
special rule if they did not already have it.

If a model within a Detachment has any upgrades included in the following section, no
model within the same army can have a Household Ranks upgrade.

So an Army either has to pick Household ranks or Dark Blessings and can’t have both in the
same army. Each type of Dark Blessing is applicable to any choice on the force organization
chart.

THE LEGIONES AUXILIA SPECIAL RULE

The Legiones Auxilia special rule is intended to represent Solar Auxilia cohorts that fight alongside
the forces of the Legiones Astartes during the Horus Heresy, showcasing the unique
specialisations, equipment and tactics they adopted in doing so. The Legiones Auxilia special rule
may only be applied to an Allied Detachment selected using the Solar Auxilia Army List and where
the Primary Detachment’s Warlord has the Legiones Astartes special rule. The Legiones Auxilia
special rule is currently intended to be used alongside a Warlord with a base version of the
Legiones Astartes special rule and may not be applied to an Allied Detachment selected from the
Solar Auxilia Army List in the same army as a Detachment containing models with the Legiones
Hereticus, Legiones Astartes (Shattered Legions) or Legiones Astartes (Blackshields) special rules.

Each variant of the Legiones Auxilia special rule is associated with the matching Legion and can
only be selected alongside a Primary Detachment whose Warlord has this corresponding Legiones
Astartes special rule – e.g., Legiones Auxilia (Dark Angels) and Legiones Astartes (Dark Angels). Any
version of the Legiones Auxilia special rule being applied to an Allied Detachment drawn from the
Solar Auxilia Army List must be selected during army selection and noted on the army roster. An
Allied Detachment drawn from the Solar Auxilia Army List which has had a version of the Legiones
Auxilia special rule applied to it still belongs to the Imperial Army Faction and the Solar Auxilia Sub-
faction. However, it is always considered to have the ‘Fellow Warriors’ level of Alliance with the
Space Marine Faction they correspond with, unless they would already have the ‘Sworn Brothers’
level of Alliance.

Additionally, if a unit which contains one or more models with the Legiones Auxilia special rule has
at least one model within 12" of a friendly unit containing one or more models with the
corresponding Legiones Astartes special rule when that unit fails a Morale check, the unit
containing models with Legiones Auxilia is immediately Pinned.
